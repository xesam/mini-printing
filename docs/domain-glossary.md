# 领域术语表

本文是产品设计与实现之前的领域先导规范。它只定义业务概念、职责和对象边界，不描述任何具体代码、文件、存储方案或当前实现状态。

核心原则：**产品层的设备与云打印 API 库定义的 `Device` 是不同对象，不得混用。**

## 领域对象

| 术语 | 所属边界 | 定义 |
| --- | --- | --- |
| 产品设备（`ProductDevice`） | 产品领域 | 产品识别、管理和操作的一台打印设备，承载设备身份及产品侧管理信息。 |
| 常用设备（`FrequentDevice`） | 产品领域 | 用户为了快速访问而保存的产品设备记录或关系。它是产品设备的使用偏好，不是云端设备对象的别名。 |
| API 设备（`ApiDevice`） | 外部 API 边界 | 为调用云打印服务而构造的接口参数对象，表示厂商 API 所需的设备标识和参数。它不属于产品领域。 |
| API 设备响应（`ApiDeviceResult`） | 外部 API 边界 | 云打印服务返回的设备信息或状态结果，反映外部系统视角下的设备。它不能直接充当产品设备。 |
| 设备视图模型（`DeviceViewModel`） | 表现层 | 为特定界面准备的展示数据，可组合产品设备信息和外部查询状态。它不是领域实体，也不是 API 参数。 |
| 开放平台账号（`CloudAccount`） | 产品领域与集成边界 | 用户用于访问某个云打印厂商开放平台的一组配置和凭据。 |
| 当前账号（`CurrentCloudAccount`） | 应用状态 | 当前被选中的开放平台账号引用，用于确定本次云端操作使用的访问上下文。 |
| 厂商（`CloudBrand`） | 集成概念 | 提供云打印服务的平台供应商。厂商标识用于区分 API 规则和访问上下文。 |
| 设备类型（`DeviceType`） | 产品领域 | 产品对打印能力或打印任务形态的分类。它描述产品业务语义，不自动等同于厂商硬件型号。 |
| 打印订单（`PrintOrder`） | 产品领域 | 用户希望设备执行的一次打印任务，表达打印内容、份数、类型等产品意图。 |
| API 订单（`ApiOrder`） | 外部 API 边界 | 为调用云打印服务而构造的订单参数对象。它是产品打印订单到厂商协议的适配结果。 |
| 打印模板（`PrintTemplate`） | 产品领域 | 可复用的打印内容结构、格式或渲染定义。 |

## 产品设备的身份

- 产品设备的身份由**厂商标识**和**厂商设备编号**共同组成：`(brand, deviceId)`。
- `deviceId` 是产品领域对厂商设备编号的统一称呼；它不是产品数据库主键，也不保证跨厂商唯一。
- 厂商 API 可能使用不同名称表示同一编号，例如 `sn`。名称差异属于 API 边界，不改变产品领域的 `deviceId` 语义。
- 产品设备的名称、备注、常用状态和使用记录属于产品信息；云端设备状态属于外部 API 查询结果，二者应分开表达。

## 对象转换

产品设备与 API 设备之间必须经过显式转换：

```text
ProductDevice
    ↓ 提取产品设备身份并适配厂商协议
ApiDevice
    ↓ 调用云打印 API
ApiDeviceResult
    ↓ 提取产品需要的外部状态
DeviceViewModel
```

产品打印订单与 API 订单遵循同样的边界：

```text
PrintOrder → ApiOrder → 厂商打印接口
```

## 边界规则

1. API 设备只在外部 API 集成边界创建和消费，不作为产品领域实体。
2. 产品设备不能直接作为厂商 API 参数；必须先转换为 API 设备。
3. API 设备响应不能直接写入产品设备；必须提取并映射所需的业务信息。
4. API 对象不承载产品名称、备注、收藏状态、产品类型等业务字段。
5. 产品对象不依赖某一家厂商 API 的方法、字段命名或类层次。
6. 页面展示对象只服务界面，不应被当作领域实体或 API 参数复用。
7. 产品 `DeviceType` 与厂商硬件型号、接口参数中的类型字段不能默认视为同一概念。
8. 在代码和文档中应使用明确名称：`productDevice`、`frequentDevice`、`apiDevice`、`apiDeviceResult`、`deviceViewModel`，避免在不同边界中都使用无限定的 `device`。

## 术语使用约定

- 称“设备”时，如果语境属于产品业务，默认指产品设备；如果语境属于厂商接口，必须明确称 API 设备。
- 称“设备编号”时，产品领域使用 `deviceId`；描述厂商协议字段时保留厂商原名，并在转换处标明对应关系。
- “在线、离线、打印能力”等由外部平台返回的事实，应标明其来源和查询时点，不与产品设备的静态身份信息混为一谈。
